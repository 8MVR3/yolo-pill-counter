# yolo-pill-counter

Дообучение YOLO11n на датасете medical-pills и подсчёт объектов на фото с отчётом в Excel.

## Структура

- `train.py` — дообучение с весов COCO, 60 эпох, вход 640, батч 16, затем проверка `model.val()`.
- `count.py` — считает объекты на всех фото в папке, сохраняет фото с рамками и подписью «Найдено: N» и таблицу `Подсчёт.xlsx`.
- `weights/best.pt` — обученная модель, `training/` — графики обучения, `examples/` — примеры подсчёта.

## Команды

```
pip install -r requirements.txt
python train.py
python count.py weights/best.pt папка_с_фото
```

## Правила

- Порог уверенности для подсчёта 0,4: на этом датасете он даёт больше точных совпадений, чем 0,5.
